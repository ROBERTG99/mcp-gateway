## Caveats

- `injection.v1`: dev and test are split per case, not per template, so every attack template in test also occurs in dev with different fills; the detector was tuned on dev, and one rule matches the generator's base64 wrapper text. Test recall therefore measures new fills of known phrasings, not new phrasings (docs/KNOWN_LIMITATIONS.md).
- `redaction.v1`: cases use a fixed set of formats; real-world recall will be lower.
- Graders are deterministic, so a delta against the baseline is a real change; the gate fails any regression beyond 1.0 pp.

Injection scoring is defence in depth, not a solution: see `docs/evaluation.md`.
