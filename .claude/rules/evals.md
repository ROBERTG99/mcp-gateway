# Eval rules

- Never edit files in `evals/datasets/test/` (the guard hook blocks it). Tune thresholds and heuristics on `dev` only.
- Datasets are generated by `cmd/datagen` with seed 20260 and are labelled by construction.
- `evals/REPORT.md` is generated by `make eval`; never edit it by hand and never invent numbers.
- A regression of more than 1.0 percentage point against `evals/baseline/` fails the gate.
